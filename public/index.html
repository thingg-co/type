Board

An Android keyboard that fixes typos with a language model running on the phone.

Download APK Source on GitHub

What it does

Board is a normal QWERTY keyboard with one difference: when you finish a word that isn't in the dictionary, a small language model looks at the last few words and the word you typed and decides what you meant. If it is confident, the word is replaced and an undo chip appears in the suggestion bar. Backspace right after a correction also puts the original back.

The model runs inside the keyboard process through llama.cpp. There is no network permission used for typing; the only download is the model file itself, which you pick and fetch from the settings screen.

Adaptive keys

As you type, the keyboard knows which letters can still continue a real word. Letters that can't are shrunk and dimmed; likely ones stay full size. The touch targets never change, so you can still type names and slang, it just gets visually quieter.

Install

  1. Download the APK and open it on the phone. Android will ask you to allow installs from this source.
  2. Open Board. Step 1 turns the keyboard on in the system settings; step 2 switches to it.
  3. Pick a model. The 0.5B model is quick on any recent phone; the 1.5B one is more accurate and best on flagship hardware. Both are stored in the app's private storage.

Without a model the keyboard still works and falls back to dictionary suggestions.

How the correction works

The prompt has a fixed part (instructions and a handful of examples) and a short per-request part. The fixed part is decoded once and kept in the model's cache, so each correction only pays for a couple of dozen tokens plus the few it generates. Output is constrained with a grammar to a single word, then checked against edit distance and the dictionary before it is allowed to replace what you typed.

Build it yourself

git clone --recursive git@github.com:thingg-co/type.git
cd type
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk

Needs Android Studio's SDK with NDK 28 and CMake 3.31. English only for now; the layout and dictionary are data files, so other languages can be added without touching the input logic.
